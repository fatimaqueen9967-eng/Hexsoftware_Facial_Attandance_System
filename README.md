🧑‍💼** Face Recognition Attendance System**

An AI-powered Face Recognition Attendance System that automatically detects and identifies individuals from 
images or webcam input and records their attendance in a CSV file with date and time. The system is built using 
Python and deployed with a simple Gradio web interface.

🚀 Features

  🎯 Face detection and recognition using AI
  📸 Supports image upload and webcam input
  🧾 Automatic attendance marking in CSV file
  ⏱️ Stores name, date, and time
  ⚠️ Prevents duplicate attendance entries
  🌐 Simple and interactive web UI using Gradio
🛠️ Tech Stack

Python 🐍
OpenCV
face_recognition library
NumPy
Gradio
CSV (for attendance storage
